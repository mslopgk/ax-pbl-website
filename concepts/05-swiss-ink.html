01/03
What is PBL

PBL은 트렌드가 아니라,
반세기 검증된 교수학습 모델입니다.

PBL(Problem-Based Learning)은 일시적인 교육 트렌드가 아닌, 반세기 동안 고등교육의 효과성을 입증해 온 정통성 있는 교수학습 모델입니다. AX-PBL은 여기에 AI를 더해 문제를 정의하고 해결하는 현대적 확장입니다.

비구조화 문제 / Ill-structured 정답이 정해져 있지 않은 현실의 복잡한 문제를 중심으로, 학습자가 주도적으로 협력·사유하며 해결책을 도출하는 역량 중심 학습(Competency-Based Learning)의 핵심.
1969
McMaster 의과대학
혁신의 출발
하워드 배로우(Howard Barrows) 교수가 주입식 의학 교육의 한계 — ‘파편화된 지식’을 극복하기 위해 PBL을 최초로 도입했습니다.
문제
지식의 파편화
암기는 했지만 진단하지 못했다
당시 의대생들은 엄청난 양의 의학 지식을 외웠지만, 정작 병원 현장에서 환자를 마주했을 때 병명을 진단하지 못하는 심각한 ‘지식의 파편화’를 겪었습니다.
해결
Ill-structured Problem
문제를 먼저 던지다
배로우 교수는 주입식 강의를 버리고, 실제 환자의 증상 시나리오를 먼저 던진 뒤 학생이 스스로 진단하고 치료법을 찾게 했습니다. 결과는 대성공, 전 세계로 확산되었습니다.
Now
Competency-Based
역량 중심 학습의 핵심
단일한 정답이 없는 복잡한 현실 세계의 문제를 중심으로, 학습자가 주도적으로 협력·사유하며 해결책을 도출하는 역량 중심 학습의 핵심입니다.
→ 01
Self-directed
자기주도적 학습

교수가 지식을 주입하는 것이 아니라, 학생이 스스로 필요한 지식을 찾아 나섭니다.

→ 02
Collaborative
협동 학습

팀원들과 소통·토론하며 집단지성으로 문제를 해결합니다.

→ 03
Ill-structured
비구조화 문제

정답이 정해져 있지 않고 현실에 존재할 법한 복잡한 문제를 해결하며 지식을 습득합니다.

→ 04
Facilitator
퍼실리테이터

교수는 ‘지식 전달자’가 아닌, 올바른 방향으로 길을 열어주는 ‘조력자·안내자’입니다.

Teaching Studio

AX-PBL 콘텐츠 7대 패키지

PNU AX-PBL Teaching Studio 플랫폼이 제공하는 핵심 구성요소.

01
3LAYER-BPF 콘텐츠
Basic → Practical → Field
기본 이론(Basic Theory) → 실무 역량(Practical Skill) → 현장 훈련(Field Training)의 3단계 구조.
02
문제해결형 AX-PBL
Problem-Solving Model
학생이 문제를 직접 발견하고, AI와 함께 확장적으로 분석한 뒤, 실행 가능한 해결안을 설계·검증하는 수업 모델. 더 넓게 보고, 깊게 정의하고, 다양하게 만들고, 엄격하게 검증합니다.
03
산업·지역 Problem Bank
Problem Bank
기업·공공기관·지역사회·학내 부서가 문제를 등록하는 문제은행. 부산대 수업과 산업·지역 현장을 연결하는 문제 매칭 시스템입니다.
04
AI Co-Design Studio
AI Co-Design Studio
AI를 검색 도구가 아니라 수업설계와 문제해결의 공동 설계자로 활용. 학생은 AI에 분석가·비판자·정책자문가·사용자 대변인 역할을 부여해 사고를 확장합니다.
05
AX Impact Portfolio
AX Impact Portfolio
학생 산출물을 역량 증빙자료, 취업·진로 포트폴리오, 우수사례, 성과보고 자료로 자동 축적합니다.
06
표준 강의계획 템플릿
Course Design Template
전공별 학습 목표와 생성형 AI 프롬프트 템플릿을 연계해, 클릭 몇 번으로 표준 강의계획서를 수립할 수 있는 교수 지원 도구.
07
역량 인증 & 시각화
Competency Certification
AI 협업 문제해결 과정을 추적하여 검증된 역량 인증서 형태로 자동 시각화·축적하는 인증 체계.
